# LeetCode 15 - 3Sum

Pattern: Two Pointers

Difficulty: Medium

## Idea

Sort the array. Fix the first number with an outer loop, skipping duplicates to avoid repeated triplets.

Use two pointers left and right over the remainder of the array to find pairs that sum to -nums[i].

If the total is 0, record the triplet; if too small, move left up; if too large, move right down.

## Complexity

* Time: O(n^2)
* Space: O(n) for sorting/output

## Mistakes

* Solved cleanly on the first accepted attempt. The key detail is skipping duplicate values for the fixed outer index (if i > 0 and nums[i] == nums[i-1]: continue) to avoid duplicate triplets.

## Recognition

Look for this pattern when you have:

* Need all unique triplets summing to a target (commonly zero)
* Sorting plus fixing one element reduces it to a two-pointer two-sum search
* Need to avoid duplicate results
